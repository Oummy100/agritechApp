# AgriTech App

AgriTech App est une plateforme web conçue pour connecter les agriculteurs avec différents acteurs du secteur agricole tels que les acheteurs, experts, ONG, climatologues et institutions publiques.

L’objectif est d’améliorer la productivité agricole, la communication et l’accès au marché grâce à une solution numérique.

## Démonstration en ligne

🔗 Site web : https://oummy100.github.io/agritechApp/

## Fonctionnalités

- Interface responsive et facile à utiliser
- Présentation de produits agricoles
- Mise en relation entre agriculteurs et acheteurs
- Plateforme de partage d’informations
- Navigation claire avec Bootstrap
- Design moderne et responsive

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- Bootstrap 5
- Font Awesome

## Installation

Pour exécuter le projet en local :

1. Cloner le dépôt

```bash
git clone https://github.com/Oummy100/agritechApp.git
```

2. Ouvrir le dossier du projet

```bash
cd agritechApp
```

3. Lancer `index.html` dans un navigateur  
ou utiliser Live Server sur VS Code.
